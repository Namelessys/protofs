Protofs is a prototype for a fluid physics simulation.

At the moment it it not much more as a projct meant to learn how a CFD could work and therefore written in the language I am most familiar with.

Protofs is written in lua/[pleal](https://github.com/namelessys/pleal) and runs on the [LÖVE2D](https://love2d.org/wiki/Main_Page) engine.
